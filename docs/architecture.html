Browser proof of concept

A call-centre conversation, without the phone line.

This architecture turns a browser tab into an English voice call: the customer speaks naturally, the agent listens, reasons, uses business tools and answers with an appropriate emotional tone. The PoC uses free-tier hosted models and keeps all credentials on the server.

System architecture

Audio in → action → expressive audio out

The customer speaks through a browser. A Hiwar realtime gateway detects turns and sends completed speech to hosted Whisper. The transcript passes to a conversation agent, which can use mock business tools and selects an emotional tone. Orpheus converts the response into expressive English speech that returns to the browser. Local voice detection can interrupt playback immediately.

What makes it feel realtime

Three control loops run around the model calls

Local loop · immediate

Barge-in

The browser detects new customer speech, stops audio playback immediately and tells the gateway to cancel the current agent turn.

voice detected→stop playback→cancel turn
Conversation loop · contextual

Emotion selection

The agent chooses a restrained service tone from the caller's words and context. It responds calmly to anger rather than imitating it.

sentiment→tone policy→voice direction
Speech loop · progressive

Sentence streaming

The agent writes concise sentences. Each completed sentence moves to speech while the next sentence is still being prepared.

text chunk→speech→queued audio

One customer turn

The event sequence behind a natural reply

  1. Listen

    The browser captures mono audio while local voice detection tracks speech and silence.

    Browser

  2. Close the turn

    A short silence marks the end of the utterance. The gateway packages only that turn for recognition.

    Hiwar gateway

  3. Understand

    Whisper returns the caller's words; the transcript appears in the call interface.

    Speech model

  4. Reason and act

    The conversation agent considers history, calls lookup_order when needed and produces structured tone plus text.

    Agent + tools

  5. Speak

    Short reply chunks are synthesized with directions such as [warm] or [calm and apologetic].

    Voice model

  6. Yield when interrupted

    New customer speech clears queued audio and starts a fresh turn without waiting for the agent to finish.

    Browser + gateway

Deployment boundary

What stays local and what leaves the application

Inside the Hiwar PoC

API credentials, session state, mock customer records, tool permissions, cancellation logic, transcript display and latency measurements remain in the browser or local server.

Sent to hosted model APIs

Caller audio is sent for speech recognition. Transcript and conversation context are sent for reasoning. Approved reply text and its tone direction are sent for voice generation.

PoC boundary: free-tier APIs are appropriate for demonstration, not a production contact centre. They provide no commitment to availability, capacity or UAE/KSA data residency. Production deployment needs contracted services, retention controls and measured regional performance.
